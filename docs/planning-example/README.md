# 从照片开始的独立规划试走

本例用于检查：一位没有参与 Skill 编写的 Agent，拿到几张宠物照片和技能文件后，是否能产出完整、可操作的素材制作计划。

测试请求为：根据照片制作写实 Windows 桌宠，用户自行在视频平台生成后交回文件；本轮先做站、坐、趴、枕爪往返，以及向左拖动走路，其他功能列入后续计划。

测试使用了项目已有的三张宠物照片，公开文档仅保留 P01、P02、P03 编号与宠物特征描述，不包含原照片、人物、私人路径或聊天记录。照片缺少标准站姿、完整尾巴和完整侧面，计划必须说明这些限制，不能冒充已确认外貌。

试走只生成规划文档，没有生成图片或视频，也没有把未来尾帧报告为已经通过。诞诞实际应用的源码与素材验证是另一项检查，详见 [源码示例](../../examples/dandan/README.md)。

## 试走产物

1. [角色与标准图](01-角色与标准图.md)：照片可确认／未知特征、统一参数和静态图提示词。
2. [动作与完整提示词](02-动作与完整提示词.md)：15 条所选动作卡，每条说明静态复用／备用图、完整动态提示词和尾帧去向。
3. [生成顺序与交接](03-生成顺序与交接.md)：按批次列出等待、输入、产物、验收和下一步。
4. [素材验收与程序交接](04-素材验收与程序交接.md)：返工、透明素材、取消与程序阶段的交接要求。
5. [独立试用报告](05-独立试用报告.md)：测试范围、发现的问题及修正后的复核。

## 复核结果

15 条动作卡、21 个提示词块和 27 个内部链接检查通过。15 动作、9 条声明路线的图检查通过；[检查用动作表](plan-actions.json) 和 [图检查结果](graph-audit.json) 一并保留。

试走发现稳定侧站和行走相位容易共用一个状态，已在技能中明确区分 WL/WR 与 GL/GR，并补上起步、循环、收步。还明确了“正常关闭始终保留”和“动画离场可以按本轮范围延期”的区别。计划没有对任何尚未生成的视频标记通过。

这些检查验证规划完整性和声明的路线，不证明未来生成视频的身份、动作或循环接缝已经合格。
