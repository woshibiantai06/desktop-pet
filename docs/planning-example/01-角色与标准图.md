# 棕白小狗写实 Windows 桌宠：角色与标准图

本轮交付是可执行的制作计划。P01、P02、P03 已实际查看；所有 I、E、V、C 编号均是待生成或待提取的未来素材，尚无新图片、新视频或程序通过验收。

阅读顺序：[本文件](01-角色与标准图.md) → [动作与完整提示词](02-动作与完整提示词.md) → [生成顺序与交接](03-生成顺序与交接.md) → [素材验收与程序交接](04-素材验收与程序交接.md)。

## 本轮范围和默认选择

制作写实 Windows 桌宠。先完成正面站立、坐姿、抬头趴姿、枕爪趴姿的待机和自然往返，再完成向画面左侧拖动时的走路进入、循环、收步、回正面。视频由使用者在自己的平台生成后回传，本计划不依赖任何指定平台按钮。

本轮不生成舔鼻、歪头、叫声、右侧走路、摸头、鼠标注视、键盘联动、自主散步、随机行为或动画出入场。它们列在后续计划中。正常关闭程序仍是本轮必须能完成的操作；本轮不要求离场动画。

## 缺失参考与推进方式

1. 最有用的补图：小狗自然四脚站立的平视全身图；朝画面左侧的平视全身侧面图；能看清尾巴自然下垂或翘起形状的图。画面须包含耳朵、四脚和尾尖，避免广角近摄。
2. 目前可先做 I-F 草稿，核对已知脸部与胸毛。标准站姿腿长、未见侧背花纹和尾巴形状属于暂定补全，不能称为已经还原真实外貌。使用者接受暂定补全后才冻结 I-F；补图到达后若冲突则升级基准版本。
3. 左转分支开始前优先补齐侧面和尾巴。若仍无补图，只能在明确接受“未见部分为生成补全”的条件下继续；否则完成正面主干，左拖保留待补参考状态。不要自动镜像出另一侧花纹。

## 项目统一画面规范

| 参数 | 统一目标与操作 |
| --- | --- |
| 画幅 | 正方形；优先 1024×1024。若平台只提供其他正方形分辨率，选其原生规格并全项目保持一致，记录实际宽高 |
| 摄影 | 固定机位、固定焦距、自然透视；机位以站立胸部附近高度为参考，坐趴时不跟随降低，不推拉、不摇移 |
| 构图 | 身体居中；正面站姿头顶约在画布上方 20%，最低接地点约在 87.5%；耳尾离边至少约 8%；转向和趴下可扩大主体周围余量，但不改变角色骨骼比例 |
| 地面 | 同一水平地面；站坐脚底和趴姿支撑部位落在同一地面参考，不强迫不同姿态等高；不画地板纹理、地平线或明显投影 |
| 光照 | 柔和、均匀、固定的正面偏上光照，棕白毛颜色稳定 |
| 背景 | 均匀中性灰色，目标 #808080；小狗以外无内容。后续用主体分割，不用把白色全部删掉的方法抠像 |
| 运动与帧率 | 目标为自然速度；平台支持时选原生 30 fps，否则保留真实原生 fps 并登记；不把导出 60 fps 当成新增真实动作细节 |
| 声音 | 本轮不需要声音；回传原始视频即可 |
| 端点 | 转换动作前后争取各稳定约 0.3–0.5 秒；循环要看实际首尾相位与速度；时长均为目标，不是平台保证 |

## I-F：现在实际执行的第一步

在支持多图参考的图片功能中，上传 P01、P03、P02，分别标为“脸部主参考”“肩颈和头身参考”“口鼻及胸毛补充”。如果只支持一张参考，先只用 P01 做草稿，再对照 P02/P03 人工检查；它不能凭空解决全身比例缺图的问题。不要直接拿头部近照当视频首帧。

可复制静态提示词：

```text
根据上传的同一只棕白小狗照片制作一张写实的正面全身站姿标准图。P01 是脸部身份主参考，P03 补充肩颈、胸毛及较自然的头身印象，P02 只补充口鼻和前胸细节。保留暖棕色头毛、自然下垂的双耳、额头中央延伸到鼻梁的白色纵纹、白色口鼻和下巴、宽白胸及白色前肢、暗棕色眼睛、棕褐色鼻头与深色鼻孔、口鼻细毛；保持照片可见的花纹差异，不改成卡通或规则对称图案。小狗头与身体正对镜头，四脚自然承重，身体放松。不要延续俯拍的大头短腿透视，不增加无依据的复杂斑纹；照片未展示的腿长、尾巴和侧背部分只做保守暂定补全，保留供核对的完整轮廓。固定机位与焦距，自然透视，镜头高度约在站立胸部附近。正方形画布，目标 1024×1024，主体居中，站姿头顶约在上方 20%，最低接地点约在高度 87.5%，耳朵、四脚、尾尖完整入画且四周至少约 8% 余量。均匀中性灰背景，目标 #808080，柔和固定正面偏上光照，无地面纹理、明显投影、文字、水印或额外物体。真实毛发和真实犬类解剖。
```

先核对身份、花纹、腿长、尾巴和完整轮廓，认可后保存 I-F_v1.png。若脸或耳形不对，先修本图，不开始所有视频。未见部分的接受只是建模选择，不是照片证据。

仅支持一张图片参考时，只上传 P01，改用这个完整版本：

```text
根据上传的 P01 棕白小狗照片制作一张写实的正面全身站姿草稿。保留照片可见的暖棕色头毛、自然下垂的双耳、额头中央延伸到鼻梁的白色纵纹、白色口鼻和下巴、白色胸前与前肢、暗棕色眼睛、棕褐色鼻头、深色鼻孔和口鼻细毛，保留真实的不规则棕白分界，不改成卡通。小狗头和身体正对镜头，四脚自然承重。原照片是俯拍近照，不沿用大头短腿透视；照片没有证明的腿长、完整尾巴和侧背花纹只能做保守暂定补全，不加复杂斑纹，等待后续核对。固定机位焦距，自然透视，镜头高度约在站立胸部附近。正方形画布目标 1024×1024，主体居中，站姿头顶约在上方 20%，最低接地点约在高度 87.5%，耳朵四脚尾尖完整入画且四周至少约 8% 余量。均匀中性灰背景目标 #808080，柔和固定正面偏上光照，无地面纹理、明显投影、文字、水印和额外物体。真实犬类解剖和毛发。
```

单图草稿仍要人工对照 P02、P03 的可见口鼻、白胸和肩颈。缺失部分未获接受时，不升级为 I-F_v1，也不开始视频。

## 备用静态图卡：默认不执行

只有对应转换视频没有可用尾帧，或平台需要预览目标尾图时才使用。已有合格 E-S/E-L/E-P/E-WL 就复用，不再新造一张。备用图先叫 I-S-target、I-L-target、I-P-target、I-WL-target；生成并认可后仍须让转换视频实际到达它，不能把不相接的图直接接进程序。

### I-S-target：坐姿备用

输入 P01、P03 和已认可 I-F；I-F 控制角色大小、机位和画布。

```text
为上传的同一只棕白小狗生成正面坐姿目标图。P01 核对暖棕头毛、自然垂耳、额头到鼻梁白纹、白色口鼻、暗棕眼睛、棕褐鼻头与深色鼻孔；P03 补充宽白胸与棕色肩颈；已认可 I-F 控制同一体型、毛色、未见部分的暂定造型、机位与画布。小狗正面坐稳，臀部接地，后腿自然折起，白色前肢伸直支撑，头自然抬起，不改变身体比例。固定机位焦距和站立胸部附近的镜头高度，正方形画布，目标 1024×1024，主体居中，最低接地点约在高度 87.5%，全身耳尾完整入画，四周至少约 8% 余量；坐姿自然比站姿低，不放大填满画面。均匀中性灰背景目标 #808080，柔和固定正面偏上光照，无地面纹理、明显投影、文字、水印和额外物体。真实毛发与犬类解剖。
```

### I-L-target：抬头趴姿备用

输入 P01、P03、I-F 和已认可 E-S；不能把另一只狗的趴姿作为身份参考。

```text
为上传的同一只棕白小狗生成正面抬头趴姿目标图。保留 P01 的暖棕头毛、下垂双耳、额头到鼻梁白纹、白色口鼻与下巴、暗棕眼睛、棕褐鼻头和深色鼻孔，保留 P03 的宽白胸及棕色肩颈；I-F 和 E-S 固定同一角色体型、已有花纹、机位、画布和暂定尾巴。小狗胸腹自然落地，后腿舒适收拢，两只前爪向前伸展，头抬起朝正前方，不跪成坐姿。镜头仍固定在站立胸部附近高度，不跟随降低，固定焦距自然透视。正方形画布目标 1024×1024，主体居中，支撑接地点约在高度 87.5%，保持自然降低后的主体高度，耳尾四爪完整入画且四周至少约 8% 余量。均匀中性灰背景目标 #808080，柔和固定正面偏上光照，无地面纹理、明显投影、文字、水印和额外物体。真实毛发与犬类解剖。
```

### I-P-target：枕爪备用

输入 P01、P03、I-F 和已认可 E-L；以 E-L 约束前爪和身体位置。

```text
为上传的同一只棕白小狗生成正面枕爪趴姿目标图。保留暖棕头毛、自然垂耳、额头至鼻梁白纹、白色口鼻下巴、宽白胸和白色前肢、暗棕眼睛、棕褐鼻头及深色鼻孔，花纹和毛发与 P01、P03 及已认可 I-F 一致。以 E-L 的躯干、两只前爪和尾巴位置为准，仅让头颈自然放低，下巴轻放两只前爪之间或其上方，鼻孔不能被爪子堵住，眼睛自然睁开；胸腹和后腿仍保持原趴姿。固定机位焦距，镜头高度保持站立胸部附近，正方形画布目标 1024×1024，主体居中，同一地面支撑点约在高度 87.5%，不放大趴姿，耳尾与前爪完整入画且四周至少约 8% 余量。均匀中性灰背景目标 #808080，柔和固定正面偏上光照，无地面纹理、明显投影、文字、水印和额外物体。真实毛发与犬类解剖。
```

### I-WL-target：左侧站稳备用

输入 P01、P03、I-F，以及补齐的朝画面左侧全身参考；没有补图时将侧背和尾巴记为已接受的暂定造型。不能把未知侧面说成真实复原。

```text
为上传的同一只棕白小狗生成鼻子朝画面左侧的完整侧身站姿目标图。P01 和 P03 核对暖棕头毛、自然下垂耳朵、额头鼻梁白纹、白色口鼻与下巴、宽白胸、白色前肢、暗棕眼睛、棕褐鼻头和深色鼻孔；已认可 I-F 约束同一体型、毛发和暂定部分。侧面补图如已提供，只用于其实际看得见的侧面花纹和尾巴；缺失部分延续 I-F 已接受的保守造型，不增添斑块。小狗鼻子明确指向画面左边，身体随之侧转，四脚自然站稳，头、胸背、后躯和尾巴属于同一只狗，不是把正面图片整体旋转。固定机位焦距，镜头高度保持站立胸部附近，自然透视。正方形画布目标 1024×1024，主体居中，最低接地点约在高度 87.5%，耳朵、四脚、尾尖完整入画且四周至少约 8% 余量。均匀中性灰背景目标 #808080，柔和固定正面偏上光照，无地面纹理、明显投影、文字、水印和额外物体。真实毛发与犬类解剖。
```

E-GL 不生成独立静态备用图。若进入步态片段没有清楚且可复现的接地点相位，返工 W02E，避免凭一张静态摆腿图冒充真实步态。
